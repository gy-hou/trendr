# TrendR v2.1.0 — Claude Code-first release

## Highlights

- **Claude Code becomes the primary runtime.** OpenClaw remains fully supported (legacy).
- New `ClaudeCodeAdapter` with `native` + `subprocess` modes (`engine/adapters/claude_code.py`).
- 4 subagents (`paper-scout`, `paper-analyzer`, `review-lead`, `verifier`) defined in `agents/*/claude-code.md`.
- 5 slash commands (`/tr research|hotspots|status|resume|template`) in `runtimes/claude-code/commands/`.
- Plugin manifest at `runtimes/claude-code/plugin.json` for Claude Code plugin install.
- `SessionStart` / `Stop` / `SubagentStop` hooks for resumable, self-healing runs.
- 8 skill sibling files (`skills/*/claude-code.md`) with Claude Code–native tool mappings.
- Runtime Router in every `SKILL.md` — dormancy model keeps runtimes isolated without deletions.
- Automated installer: `./install.sh --claude-code [--user|--project]`.

## Breaking Changes

- **Runtime detection priority changed** in the v2.1.0 Claude Code rollout.
  Historical note: the current unified cross-runtime contract is `TRENDR_PLATFORM > OPENCLAW_SESSION_ID > CODEX_* > CLAUDE_CODE_* > cli`, as documented in `AGENTS.md`.

## Migration

**OpenClaw users**: no changes required. Behaviour is unchanged. Your `supervisor.py`, `SOUL.md` files, and OpenClaw installer are untouched.

**Claude Code users**:
```bash
./install.sh --claude-code --user   # install into ~/.claude/
# or, once marketplace-enabled:
claude /plugin install trendr
```

Then start a run with:
```
/tr research "your topic" --depth B
```
